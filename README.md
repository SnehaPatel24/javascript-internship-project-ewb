
# Interactive Product Inventory & Analytics Dashboard

## Project Overview
This project is a JavaScript-based inventory management and
analytics application. It allows users to add products, assign
categories, calculate inventory value, and generate reports.

## Features
- Add products using prompt()
- Validate product names and prices
- Categorize products as Budget, Standard, or Premium
- Calculate total inventory value
- Filter affordable products
- Generate formatted inventory reports
- Calculate tax and discount prices

## Technologies Used
- HTML5
- JavaScript

## JavaScript Concepts
- Variables and data types
- Operators and type conversion
- Conditional statements and switch
- Loops, break, and continue
- Functions and arrow functions
- Arrays and objects
- forEach(), filter(), and map()

## How to Run
1. Download or clone this repository.
2. Open capstone.html in Google Chrome.
3. Enter a product name and price in the prompts.
4. Right-click the page and select Inspect.
5. Open the Console to view inventory reports.
